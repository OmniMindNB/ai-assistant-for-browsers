# PDF 侧边栏快捷方式

侧边栏现有的「总结本页」和「翻译划词」应直接使用当前 Runi PDF 阅读器。总结提取所有页的文字，翻译读取文档中当前选中的文字。继续使用现有模型、对话与快捷指令配置。

背景页向已打开的 Runi 阅读器请求文档数据。阅读器复用已加载的 PDF.js 文档，可读取未渲染的页面及 Chrome 转交的本地、在线文档。重新请求文件 URL 会漏掉一次性链接和部分本地文件，网页 DOM 又只能反映渲染的部分，因此采用阅读器内读取。

PDF 全文先经过现有脱敏。正文在首轮预算内时一次性提交，超出时提供逐段读取的偏移量，以支持全文总结。无文本、未加载或限制复制的文档直接反馈原因。系统 PDF 阅读器中的文件可先用「在 Runi 中打开 PDF」打开。
