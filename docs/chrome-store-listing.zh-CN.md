## 详细说明

```text
Runi 是浏览器侧边栏里的 AI 助手。它不只回答问题，还能直接在网页上动手：填表、点按钮、翻页、整理数据。你用一句话说清要做什么，剩下的交给它。

网页，如你所愿。

【它能帮你做什么】

• 自动填表：说一句“用这些信息帮我把表单填好”，Runi 会识别字段并填写，再读回核对每一项是否真的写进去了。下拉框、单选框和网站自研的组件也能处理。
• 网页自动化：点击、输入、选择、滚动、翻页、打开新标签页，多步操作连续完成。适合后台录入、批量设置和各种重复的网页操作。
• 保存任务，一键重放：一次成功的操作可以“保存为指令”，下次在相似页面输入 / 选中它就能重做，不用再描述一遍。
• 总结与问答：总结当前网页，或针对页面内容提问，回答基于页面原文。也可以附加文本、图片和 PDF 一起提问。
• 划词翻译与润色：在页面上选中文字，点击“问 Runi”气泡，直接翻译、解释或改写。
• 跨标签页：在输入框输入 @ 选择其他标签页，把多个页面的内容一起交给 AI 对比、汇总。
• 整理页面数据：把页面上的列表、表格整理成你要的格式；数据量大时，Agent 可以运行一段脚本一次完成。
• 看懂页面实现：开发者可以让它检查 DOM、样式、脚本和计算样式，解释页面是怎么做的、为什么显示不对。
• 看截图：使用支持图片的模型时，它可以根据页面截图判断布局、按钮状态和 canvas 内容。

【始终由你掌控】

• 检测到表单提交时，每次都会暂停，等你批准后才提交。
• 执行中随时可以接手：你一动鼠标或键盘，Runi 就会暂停，询问继续还是就此停下。
• 密码和支付字段不会被读取，也不会被填写。
• 发送给 AI 之前自动脱敏：内建手机号、邮箱、身份证号、银行卡号规则，也可自定义。命中的内容会被整体替换成占位符。

【使用你自己的模型】

支持 DeepSeek、OpenAI，以及任何 OpenAI 兼容或 Anthropic（Claude）兼容的接口，包括自定义端点。Runi 本身免费，模型费用由你选择的服务商收取。

三步开始（以 DeepSeek 为例）：
1. 登录 DeepSeek 开放平台，创建并复制 API Key。
2. 打开 Runi 侧边栏，点击未配置提示中的“设置”，在“模型 Provider”中点击“添加 Provider”，快速预设选 DeepSeek（Base URL 和模型会自动填好）。
3. 粘贴 API Key 后点击“添加”，回到侧边栏即可开始对话。

【隐私】

Runi 采用本地优先设计：Provider 设置、API Key、界面偏好和对话历史保存在你的浏览器中；PDF 文本在本地提取，不作为 PDF 内容持久化。Runi 不运营开发者后端，不接入分析或广告 SDK。当你发起 Agent 请求时，即表示你指示 Runi 根据完成该请求的需要，将 API Key、当前提示词、近期对话上下文、与当前页面有关的工具结果，以及你为该请求选择的文件内容，由扩展直接发送到你配置的 AI Provider 端点，并由该 Provider 按其自身条款和隐私政策处理。只有在你打开产品并主动发起操作后，Runi 才会读取或修改页面。

【须知】

• 已知页面操作会自动执行；检测到的表单提交每次都会请求批准。
• 运行脚本需要在扩展详情页打开“允许用户脚本”。脚本运行在与页面隔离的环境中，脚本自身的网络接口被禁止；这不能阻止页面跳转或经由页面元素发出的请求，脚本触发的表单提交也不经过确认步骤。
• 截图是图片，不经过文本脱敏规则。
```
